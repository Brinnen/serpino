Teknisk SEO som tar bort det som hindrar er.

Innehåll kan inte rädda en sajt som Google inte kan crawla, som visar en annan version för användaren än för botten, eller som tar tre sekunder på mobil i Trelleborg.

Vad vi faktiskt gör

Vi börjar i Search Console och i källkoden, inte i ett snyggt slide-däck. Vanliga fynd på svenska sajter: www och non-www som båda svarar, paginering som indexeras, kanoniska taggar som pekar på sig själva fel, och JavaScript-ramverk som skickar tomma skal till Googlebot.

  • Indexering och crawlbudget – vad som ska in, vad som ska ut
  • Omdirigeringar, HTTPS, hreflang om ni har flera marknader
  • Kanonisering av parametrar, utskriftssidor och sortering
  • Core Web Vitals: LCP, INP, CLS – mätt på de sidor som säljer
  • Strukturerad data för organisation, FAQ, produkt och recension där det stämmer

Varför den här sajten är statisk

Det är en demonstration. HTML och CSS räcker långt. Om er butik behöver React är det fint – då ser vi till att rendering och metadata ändå når sökbotten. Teknikvalet är ert. Synligheten är uppdraget.

En teknisk genomgång som projekt: från 18 000 kr. Fortsatt teknik tar vi som nästa uppdrag om ni vill — se priser.
